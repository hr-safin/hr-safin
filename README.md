## 🌍 About Me

I'm a full stack developer from **Dhaka, Bangladesh**, focused on turning ideas into fast, scalable and polished web products. I design responsive interfaces, build robust REST APIs and real-time backends, and optimize the data layer underneath them. I've shipped real projects for clients, from marketplaces to admin dashboards, and I care about clean architecture as much as pixel-perfect UI.
